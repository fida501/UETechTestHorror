# UETechTestHorror
Technical Test - Horror games

## Project Overview

A first-person horror experience developed in Unreal Engine 5 for the Bumi Studio technical test.
This game is a first person POV horror games with the main reference of backroom. Where player need to find a key on a rooms and unlock the door.
I work on this project about 6 days.

**Genre:** First-Person Horror  
**Engine:** Unreal Engine 5.8
**Platform:** Windows  
**Playtime:** Approximately less than  minutes

## How to Run

### Playable Build
1. Download or extract the Windows build.
2. go to inside the folder.
3. Open the `HorrorTechTest.exe` file.

### Controls
| Input | Action |
|---|---|

## Horror Direction

I wanted to create a horror atmosphere that makes the player feel isolated and uneasy while exploring an unfamiliar, liminal space room. The environment is designed to create the feeling of a liminal space, where everything feels strangely empty, unfamiliar, and unsettling.

## Technical Decisions
1. I decided to create a backroom horror vibes because on the first thing when i create the level, i want to recreate some aspect from my home and while creating it i thought that with some lighting setup, it has a backroom vibes in it and i decided to go with it.
2. decided to create horror random event like falling chair, random chair spawn to make the player unease about the place
3. To increase the horror vibes, I decided to add some vhs old recording materials to the post processing.
4. Decided to create a hallway because i personally feels like a long hallway with low light feel 'horror' to me in a weird way, especially in a midnight at cinema(pesronal experience)
5. Decided to add some lamp ambience and sound effect to increase the horror vibes
6. for the last objective, player need to walk through the hallway to make them feel unease in the middle of empty hallway during walking to the last objective
7. 

These decisions were made to support the intended horror atmosphere while keeping the implementation manageable within the technical test timeframe.

## Known Issues
1. I run a playtest on some people with different device. The main issues is, when played on some laptops, the first room lighting is so low somehow even with max brightness. I think this is the main problem, I decided to tell my friends to max their brightness and turn off their lamp when this problem occurs.
2. On device that occurs the number 1 problem, some of the object is too blend with the darkness make it unnoticeable, if stuck and doesn't know what to do try to explore the corner of the room
Other than that, i feel like the games is running well unless proven otherwise.
